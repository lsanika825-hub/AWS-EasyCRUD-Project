# AWS EasyCRUD – Cloud Deployment Project

## Project Overview
A full-stack student registration application deployed on AWS using cloud infrastructure and DevOps practices.

## Technologies Used
- AWS EC2
- Amazon VPC
- Amazon S3
- Amazon RDS MySQL
- Application Load Balancer
- Auto Scaling
- CloudWatch
- SNS
- AWS Systems Manager
- Linux
- Java Spring Boot
- React
- Git and GitHub

## Key Features
- Configured VPC with public and private subnets.
- Deployed backend application on EC2.
- Hosted frontend using Amazon S3.
- Configured RDS MySQL database.
- Used Application Load Balancer for backend traffic.
- Configured Auto Scaling for application scalability.
- Implemented CloudWatch monitoring and alarms.
- Configured SNS notifications.
- Used Systems Manager for private instance management.

## Architecture
React Frontend → Amazon S3 → Application Load Balancer → EC2 Backend → Amazon RDS MySQL
